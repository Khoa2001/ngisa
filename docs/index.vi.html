NGISA

Chạy nhiều agent Claude Code song song trên một repo. Chúng viết code, test và review. Chỉ bạn được merge.

NGISA (NGƯỜI GIÁM SÁT) lên plan cho task, giao từng phần cho các worker, cho review mọi nhánh, rồi dừng ở draft PR để bạn quyết định.

Ảnh minh họa, không phải bản ghi thật.

Đọc

Sơ đồBố cục cửa sổ và luồng từ ý tưởng đến merge trên một trang. Thiết kế đầy đủVai trò, hook, các điểm người quyết định, giới hạn gói. Lab quickstartCài script và thử trong một bản sao dùng xong bỏ (tiếng Anh). Mục lục tài liệuMọi tài liệu, cấu trúc repo và các script.

Dùng thử

make-lab ~/Projects/<your-repo>
repo-tab ~/lab/<your-repo>

Cần macOS, WezTerm, jq và Claude Code bản mới. Cài script trước: xem Lab quickstart.
