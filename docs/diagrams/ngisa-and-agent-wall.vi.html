Từ ý tưởng đến merge

NGISA · OpusImplementer · Sonnet, worktree riêngBạn quyết
  1. Ý tưởngBạn gõ task cho NGISA.
  2. Brainstorm và specBạn duyệt spec.
  3. Plan và chia taskFile mỗi task được sửa. Bạn duyệt plan.
  4. agent-wall.shTạo tối đa 3 agent và mở pane cho chúng.
  5. Implementershelfie-cache, shelfie-sync, shelfie-ui: worktree riêng, TDD, test xanh. Mỗi con báo cáo cho @NGISA.
  6. gate-checkMột script so sánh file gate và cấu hình lint. Có khác biệt thì dừng merge và chờ bạn.
  7. Feature branchci_local.sh và draft PR.
  8. CI + Claude reviewTrên GitHub / GitLab.
  9. Merge vào mainChỉ bạn, hook chặn agent.

Việc chỉ bạn làm

  • SpecBạn thật sự muốn gì
  • Plan và cách chia taskChia sai là conflict ở mọi agent
  • Đọc diffBạn là reviewer; không có review agent
  • Merge, release, publishHook chặn agent làm việc này
  • Dữ liệu CCCD / PIITự đọc, lần nào cũng đọc
  • Cảm giác trên máy thậtCamera, UX quét thẻ, mỗi feature một lần

Giới hạn gói Max

  • 3 mỗi tab, 4 đến 5 tổngagent mỗi tab repo, và chạy cùng lúc ở mọi repo.
  • Tốn quota gấp khoảng N lầnvới N agent. Chung quota 5 tiếng và tuần.
  • Sonnet cho implementerOpus chỉ cho NGISA.

Cài đặt đầy đủ (file agent, script agent-wall.sh, luật hook) nằm ở one-terminal-orchestrator.vi.md.

Thử nghiệm. Mỗi lần chạy được ghi trong docs/runs/ làm dữ liệu nghiên cứu.
