NGISA

Run several Claude Code agents in parallel on one repo. They write, test and review. Only you merge.

NGISA (NGƯỜI GIÁM SÁT, "the supervisor") plans a task, hands the pieces to workers, has every branch reviewed, and stops at a draft PR for you.

Illustrative mock-up, not a recording.
